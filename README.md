# Penalty

과태료·주민 신고 **정보 허브** (신고 접수 앱이 아님).

- 도메인: `penalty.pe.kr`
- 포지션: 검색 유입 → 유형별 안내 → 안전신문고·국민신문고 딥링크
- 수익: AdSense / 쿠팡파트너스 예정
- Cloudflare Pages가 `main` 푸시마다 빌드·배포합니다.

```bash
npm install
npm run dev
```

## 쿠팡 파트너스

글 하단 카드는 `data/influencer-products.csv`에 적어 둔 상품 이름과 `https://link.coupang.com/...` 정적 링크만 사용합니다. 방문, 빌드, 배포는 쿠팡 API를 호출하지 않습니다. 이 레포의 쿠팡 HTTP 호출은 **시간당 0회**입니다. `ads-partners.coupang.com/g.js` 다이나믹 배너는 쓰지 않습니다.

페이지 카테고리에 해당하는 행의 상품 이름을 카드 제목으로 보여 줍니다. 같은 이름은 여러 글이 함께 씁니다.

| 상품 이름 | 카테고리 |
| --- | --- |
| 스마트폰 연동 2채널 블랙박스 | 교통 |
| 초소형 휴대용 카메라 | 주정차, 반려, 생활, 포상 |

상품을 바꿀 때는 CSV에 이름과 링크를 고칩니다. 검색 API로 다시 받아 오지 않습니다.

공식 한도는 검색 API 시간당 10회, 리포트 API 시간당 50회, 모든 API 분당 100회, 파트너스 웹 링크 생성 분당 50회입니다. 초과 경고가 3회 쌓이면 이용이 제한될 수 있습니다.
