# Penalty

과태료·주민 신고 **정보 허브** (신고 접수 앱이 아님).

- 도메인: `penalty.pe.kr`
- 포지션: 검색 유입 → 유형별 안내 → 안전신문고·국민신문고 딥링크
- 수익: AdSense / 쿠팡파트너스 예정
- Cloudflare Pages가 `main` 푸시마다 빌드·배포합니다.

```bash
npm install
npm run dev
```

## 쿠팡 파트너스

매칭 키는 **카테고리**입니다. 목록과 상세를 빌드할 때 그 키로 `data/products.csv`의 상품을 붙입니다. 방문, 빌드, 배포는 쿠팡 API를 호출하지 않습니다. 이 레포의 쿠팡 HTTP 호출은 **시간당 0회**입니다. `ads-partners.coupang.com/g.js` 다이나믹 배너는 쓰지 않습니다.

`data/categories.csv`는 선택입니다. `popular=1`인 카테고리를 파일 순서대로 보고, 그 카테고리 상품을 폴백으로 씁니다. 맞는 상품이 없는 숙박·도로 파손이 이 경로입니다. 고르는 순서는 고정이고, 랜덤이나 검색 API를 쓰지 않습니다.

| 상품 이름 | 카테고리 |
| --- | --- |
| 스마트폰 연동 2채널 블랙박스 | 교통 |
| 초소형 휴대용 카메라 | 주정차, 반려, 생활, 포상. 주정차가 인기 카테고리라 숙박·도로 파손 폴백도 이 상품 |

상품을 바꿀 때는 CSV의 이름과 `https://link.coupang.com/...` 링크를 고칩니다. API로 다시 받아 오지 않습니다. `scripts/coupang-batch.mjs`는 배치 수집 입구이고 빌드에 연결되어 있지 않습니다. 한도는 `scripts/coupang-guard.mjs`에 공식 한도보다 낮게 고정해 두었습니다. 검색 API 시간당 10회, 리포트 API 시간당 50회, 모든 API 분당 100회, 파트너스 웹 링크 생성 분당 50회. 이 스크립트의 시간당 상한은 6회입니다.
